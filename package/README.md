# 曲库伴侣 (MusicMate) - 飞牛应用安装包规格

本目录为遵循飞牛私有云（fnOS）官方规范的 `.fpk` 格式应用包源码工程。

## 目录结构说明

- `manifest`：飞牛应用中心元数据声明（应用包名、版本号、中文显示名、端口、描述等）。
- `app/docker/docker-compose.yaml`：Compose 编排定义，规范挂载用户授权目录与沙盒数据。
- `app/ui/`：飞牛桌面的图标与入口定义（`config`、图标文件）。
- `wizard/`：飞牛应用中心安装与配置向导（`install` 与 `config` 页面），提供可视化目录选择。
- `cmd/`：应用生命周期钩子（安装、升级、卸载、启动、停止）。
- `config/`：应用特权与资源限制配置（`privilege`、`resource`）。

## 安全与权限准则

1. **目录隔离**：仅挂载用户在向导中授权的“原始文件夹（只读）”与“整理后文件夹（读写）”，以及系统提供的应用数据目录。
2. **零特权**：不申请 root 提权，不申请 Docker socket，不使用 sudoers。
3. **数据安全**：卸载应用默认不删除用户的原始音乐库或整理后的正式曲库。
